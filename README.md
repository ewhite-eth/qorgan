# Qorǵan Clinic Desk (MVP)

Final exam MVP for AITU Technology Entrepreneurship, group CS-2416.
Bilingual (English and Kazakh) web desk: a clinic administrator reports an IT problem, a Qorǵan analyst coordinates the fix, and the director sees measured call-back and restore times.

Demo access: clinic code `QOR-01`, analyst PIN `2416` (demo codes, not real security).

- `index.html`: the whole app (HTML, CSS, JavaScript, no build step)
- `supabase_setup.sql`: table and access policies for the shared database

No patient data is collected. Sample data in the app is labelled.
